## 🎨 Design Philosophy

Forge Athletics was designed around the idea of transforming a traditional gym website into a **high-end digital fitness experience**.

The design focuses on:

> **Strength. Performance. Motion. Discipline.**

Instead of relying on a standard template structure, the interface uses large typography, cinematic imagery, interactive elements, depth effects, and carefully choreographed animations to create a strong visual identity.

## 🎯 Responsive Design

Forge Athletics is designed to provide a consistent experience across:

* 📱 Mobile
* 📱 Tablet
* 💻 Laptop
* 🖥️ Desktop
* 🖥️ Large displays

The interface adapts its layout, typography, interactions, and animations according to screen size and device capabilities.

Heavy desktop-only effects are reduced or disabled on touch devices to maintain a smooth experience.

---

## ⚡ Performance

The project focuses on maintaining a balance between visual quality and performance.

Performance considerations include:

* Lazy-loaded imagery
* GPU-friendly animations
* Transform-based motion
* Reduced unnecessary DOM operations
* Responsive animation intensity
* Optimized visual effects
* `prefers-reduced-motion` support

The goal is to make the website feel **premium without sacrificing usability or performance**.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ubaidullahzafar789-cyber/forge-athletics.git
```

### 2. Navigate into the project

```bash
cd forge-athletics
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the local development URL

Vite will provide a local development URL in your terminal.

---

## 📦 Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
